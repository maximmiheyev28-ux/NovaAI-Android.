# Фриланс-пульт (Android)

Мобильное PWA-приложение для учёта заказов, подготовки откликов и просмотра подборки удалённых проектов.

## Автоматический поиск
- GitHub Actions ежедневно запускает бесплатный сборщик из `freelance-pult/collect_fl_jobs.py`.
- Сборщик использует публичный JSON API Himalayas и публичный RSS FL.ru, если он доступен. В API берутся новые удалённые вакансии и фильтруются по указанным ограничениям страны: Россия или worldwide.
- Запись списка идёт в отдельную ветку `jobs-feed`, чтобы обновление вакансий не требовало пересборки статического сайта.
- Панель загружает JSON из ветки `jobs-feed` и показывает до 10 подходящих проектов. Карточки содержат прямую ссылку подачи/просмотра, дату, предполагаемое совпадение, бюджет/валюту, компанию, географию, тип занятости и предупреждение о необходимости проверить выплаты.
- Himalayas требует видимую атрибуцию; источник указан в карточках, а приложение даёт прямую ссылку на сайт.

## Возможности панели
- Открывает обновляемую автоматически подборку, даёт вручную обновить ленту, сохранить заказ и подготовить черновик отклика.
- Оценивает текст объявления, выявляет некоторые распространённые рискованные формулировки, пытается найти бюджет и срок.
- Ведёт статусы/суммы/сроки, калькулятор, черновики и резервные копии JSON.
- Поддерживает попытку импорта текста из буфера обмена на Android; если браузер не разрешит доступ, вставь текст вручную.

## Ограничения и безопасность
- API Himalayas обновляется примерно раз в сутки; RSS может быть недоступен или возвращать старые/закрытые объявления. Проверь страницу объявления, срок, работодателя и требования перед откликом.
- API не подтверждает возможность регистрации из России или вывода заработка на российскую карту. Перед подачей уточни страновые ограничения, допустимую валюту и реальный способ выплаты.
- Оценка совпадения и риск-фильтры эвристические, поэтому могут ошибаться и не гарантируют безопасность.
- Приложение не входит в аккаунты бирж, не обходит CAPTCHA, логин или блокировки, не отправляет отклики, не принимает и не инициирует платежи; не гарантирует заказов или дохода.
- Данные о твоих сохранённых заказах и черновиках хранятся локально в браузере и не синхронизируются между устройствами. Экспортируй резервную копию.
- Не сообщай пароль, банковский PIN, CVV или SMS-коды; не устанавливай присланные APK и не плати за «активацию» заказа или выплаты. Не принимай и не пересылай деньги третьих лиц.
