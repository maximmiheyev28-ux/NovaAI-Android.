# Фриланс-пульт (Android)

PWA-панель для поиска подходящих проектов Kwork, подготовки черновиков отклика и учёта статусов/выплат.

**Сайт:** https://freelance-pult-android.onrender.com  
**Биржа:** https://kwork.ru/projects

## Автоматическое обновление Kwork

- GitHub Actions запускает сборщик каждые 30 минут по расписанию `17,47 * * * *` UTC, а также после изменений кода и вручную.
- Сборщик ориентирован на общий список проектов Kwork (`https://kwork.ru/projects`) — не на раздел «Любимые»/избранное. Он читает общедоступную страницу без входа в аккаунт, отправки откликов и финансовых действий. Он не обходит CAPTCHA, авторизацию или технические ограничения. Перед дальнейшим использованием необходимо соблюдать действующие правила Kwork; если доступ публичной страницы ограничен или правила меняются, сбор автоматизированно не расширяется.
- Обрабатывается только первая публичная страница общего списка «Все». Это не полный каталог: часть проектов может находиться на следующих страницах и не попасть в текущую подборку.
- Опубликованная лента находится в отдельной ветке `jobs-feed`, файл `freelance-pult/jobs.json`. Изменения ленты не должны запускать сборку статического сайта.
- Скрипт сохраняет краткую диагностику причин исключения объявлений в логах GitHub Actions. Названия исключённых проектов не публикуются в самой ленте.
- Предпочитаются задачи с результатом, который можно подготовить инструментами ChatGPT: тексты, поздравления, переводы, документы, таблицы, исследования, код и отдельные изображения. Специализированные CAD-чертежи, архитектурное проектирование, управление рекламными кабинетами, рассылки/обзвоны, накрутки, физические работы и задачи с небезопасными условиями исключаются.
- Оценка — предварительный фильтр выполнимости, а не гарантия найма или выплаты. Перед откликом проверь оригинальную карточку, требования, сроки, цену и доступность вывода средств.

## Уведомления Telegram (необязательно)

Чтобы получать сообщения о новых релевантных объявлениях, добавьте в GitHub Repository → Settings → Secrets and variables → Actions → New repository secret:

- `TELEGRAM_BOT_TOKEN` — токен собственного Telegram-бота от BotFather.
- `TELEGRAM_CHAT_ID` — ID чата. Открой чат бота и нажми Start; затем получи chat ID через Bot API `getUpdates` или собственный клиент.

Не помещайте секреты в код или публичные файлы. Без обоих секретов обновление ленты продолжает работать, но уведомления не отправляются. Telegram получает только новые проекты Kwork с оценкой от 65/100 и возрастом не более 72 часов. Перед откликом всё равно требуется ручная проверка.

## Возможности панели

- Показ актуальной подборки проектов Kwork с прямыми ссылками.
- Сохранение интересных проектов, статусов, сроков и предполагаемых сумм.
- Подготовка черновика отклика и плана выполнения; отправка заказчику остаётся ручной.
- Локальное хранение пользовательских заметок в браузере текущего устройства; используй экспорт резервной копии для переноса на другое устройство.

## Безопасность

Не плати за регистрацию, «активацию» или разблокировку выплаты. Не сообщай пароль, CVV или SMS-код, не устанавливай присланные APK и программы удалённого доступа, не принимай и не пересылай чужие деньги. Не обещай заказчику профессиональную квалификацию, опыт или доступ, которых у тебя нет.

## Установка на Android

Открой сайт в Chrome → меню ⋮ → «Добавить на главный экран».
