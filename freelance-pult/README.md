# Фриланс-пульт (Android)

Адаптивное PWA-приложение для локального учета заказов и откликов.

## Ограничения
- Не подключается к API FL.ru, не сканирует сайт автоматически и не отправляет отклики.
- Не хранит пароли и банковские реквизиты, не принимает и не инициирует выплаты.
- Не гарантирует заказы или доход; требует ручного контроля качества, сроков и договоренностей.
- Данные хранятся локально в браузере, не синхронизируются между устройствами. Используйте экспорт JSON.

## Публикация
В репозитории откройте Settings → Pages → Build and deployment → Source: GitHub Actions. После сохранения workflow опубликет содержимое этой папки по HTTPS. Затем на Android откройте адрес в Chrome и выберите меню ⋮ → «Добавить на главный экран».

## Важно
Ставки в калькуляторе — пример для описанного FL.ru сценария выплат физлицу; проверьте действующие условия и возможность перечисления на конкретную карту перед работой.
