# Фриланс-пульт (Android)

Мобильное PWA-приложение для учёта заказов, подготовки откликов и просмотра автоматически собираемой подборки проектов FL.ru.

## Автоматический поиск
- GitHub Actions по расписанию (примерно каждые 6 часов) читает публичные RSS-ленты FL.ru, опубликованные для подписчиков.
- Сборщик использует обычные HTTP GET-запросы к RSS. Он не входит в аккаунт, не обходит капчу или ограничения, не сканирует закрытые страницы и не отправляет отклики.
- Подборка включает прямые ссылки на проекты из RSS, опубликованное время (если указано), извлечённый из текста бюджет/срок, тематическую оценку и предупреждения по отдельным признакам риска.
- Результат публикуется в отдельной ветке `jobs-feed`; фронтенд загружает её JSON из raw.githubusercontent.com. Это позволяет обновлять выдачу без регулярной пересборки статического сайта.
- Первый результат появится после успешного выполнения workflow. В GitHub → Actions можно проверить запуск «Refresh FL.ru job feed». Если workflow выключен или RSS недоступен, в панели может не быть свежих объявлений.

## Возможности панели
- Показывает до 10 подходящих проектов из последней RSS-выборки.
- Позволяет открыть объявление, сохранить его в «Заказы» и подготовить черновик отклика.
- Оценивает вручную вставленные объявления, извлекает некоторые бюджеты и сроки, показывает распространённые предупреждения.
- Отслеживает статусы, сроки, суммы и выплаты; поддерживает импорт/экспорт резервной копии JSON.

## Ограничения и безопасность
- RSS может содержать уже закрытые проекты; оценка не подтверждает, что заказчик всё ещё выбирает исполнителя. Проверяйте объявление на странице перед откликом.
- Тематическая оценка и предупреждения — эвристика; она может ошибаться и не гарантирует добросовестность заказчика.
- Автоматические регистрации, подача откликов и финансовые действия не выполняются. Выплаты на карту не инициируются и не гарантируются.
- Возможность регистрации/вывода в Россию, комиссия и валюта должны проверяться отдельно в правилах площадки и аккаунте до принятия работы.
- Данные заказов и черновиков хранятся локально в браузере, не синхронизируются между устройствами. Экспортируйте резервную копию время от времени.
- Не сообщайте пароль, CVV, банковский PIN, коды из SMS; не устанавливайте присланные APK, не переводите деньги за «активацию» работы/выплаты и не соглашайтесь принимать и пересылать чужие деньги.
