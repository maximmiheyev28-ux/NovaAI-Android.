# Фриланс-пульт (Android)

PWA-панель для учёта заказов, подготовки черновиков отклика и контроля статусов/выплат. Сайт: https://freelance-pult-android.onrender.com.

## Фоновое обновление заказов

- GitHub Actions запускает сборщик каждые 30 минут по расписанию `17,47 * * * *` UTC, а также после изменений кода и вручную. Планировщик может задерживать отдельные запуски.
- Сборщик использует только публичные endpoints: JSON API Himalayas, Jobicy и Remote OK, а также публичный RSS We Work Remotely. Исходные ссылки остаются в каждой карточке.
- Результат записывается в отдельную ветку `jobs-feed` как `freelance-pult/jobs.json`. Обновление данных не запускает сборку статического сайта.
- При временной недоступности источников предыдущие карточки могут сохраняться не более 36 часов; объявления старше 14 дней удаляются из кэша. Ни API, ни RSS не гарантируют, что заказ всё ещё открыт.
- Отбираются релевантные задания по текстам, переводам, редактированию, карточкам товаров, заполнению данных, контенту, транскрибации, виртуальной помощи и смежным цифровым задачам. Требование иметь компьютер само по себе не является причиной исключения.
- Явные страновые ограничения фильтруются. Worldwide/EMEA/неуказанная география сопровождается предупреждением: право резидента России на найм и вывод на российскую карту не подтверждается самим источником.
- Сборщик не авторизуется на площадках, не обходит CAPTCHA/защиту, не отправляет отклики и не совершает финансовых действий.

## Kwork — отдельный приоритет

Кнопка Kwork ведёт на официальную публичную биржу проектов: https://kwork.ru/projects. Kwork не включён в автоматический сбор: пользовательские условия площадки ограничивают несанкционированных ботов и автоматическое извлечение данных. Для Kwork используйте официальный сайт и разрешённые поисковые результаты вручную; автоматические отклики не выполняются. Ежедневный отчёт ChatGPT начинает поиск с Kwork, но показывает только подтверждённые прямые карточки.

## Уведомления Telegram (необязательно)

Чтобы получать сообщения о новых релевантных объявлениях, добавьте в GitHub Repository → Settings → Secrets and variables → Actions → New repository secret:

- `TELEGRAM_BOT_TOKEN` — токен собственного Telegram-бота, выданный BotFather.
- `TELEGRAM_CHAT_ID` — ID чата для уведомлений. Создайте бота, откройте его чат и нажмите Start; затем получите chat ID через Bot API `getUpdates` или свой клиент бота.

Секреты добавляйте только в GitHub Settings, не в код сайта и не в публичные файлы. Если секреты не заданы, лента всё равно обновляется в фоне, но Telegram-уведомления пропускаются. Скрипт выбирает только новые, релевантные, не помеченные как критически рискованные объявления с оценкой от 65/100 и публикацией за последние 72 часа. В сообщении будут прямая ссылка, источник, оценка, оплата и география.

## Возможности панели

- Показывает автоматически обновляемую подборку с прямыми ссылками, позволяет сохранить заказ и подготовить черновик отклика.
- При открытом сайте может автоматически подготовить локальную карточку, черновик и план для нескольких новых релевантных задач. Ничего не отправляется заказчику автоматически.
- Помогает вести статусы, сроки, суммы, черновики, оценку дохода и резервные копии JSON.
- Данные пользователя и локальные черновики хранятся в браузере текущего устройства; экспортируйте резервную копию, если она нужна на другом устройстве.

## Проверки безопасности

Не платите за регистрацию или «разблокировку выплаты», не сообщайте пароль, CVV или SMS-код, не устанавливайте присланные APK и программы удалённого доступа, не принимайте и не пересылайте чужие деньги. Автоматический рейтинг не гарантирует, что заказ открыт, вы допущены к работе или сможете получить выплату. Всё нужно проверить в оригинальной карточке.

## Установка на Android

Откройте сайт в Chrome → меню ⋮ → «Добавить на главный экран».
