Облачные модели и Совет ИИ

Совет запускает настроенные API параллельно. Если локальная Nova уже скачана, она тоже участвует; достаточно одного облачного API + локальной модели. Для двух облачных моделей локальная загрузка не обязательна.

Вторая облачная модельДополнительный участник Совета ИИ
Третья модель (необязательно)
ПриватностьПри облачном запросе сообщения передаются выбранному сервису. Его правила хранения данных могут отличаться от правил Nova. Не отправляйте пароли или другие секреты.
Хранение ключейКлючи сохраняются в локальных данных WebView, а не в защищённом Android Keystore. Подключайте только проверенных провайдеров.
